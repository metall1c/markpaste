Обновлено: 2026-10-19. Приоритеты из ТЗ: **M** — обязательно для 1.0, **S** — желательно, **C** — вторая очередь.
Отметки: ✅ сделано и проверено · 🟡 сделано, не проверено или частично · ❌ нет.

## Главный сценарий на KDE Plasma (Wayland)

Работает целиком и проверен пользователем: Print → область → метки и комментарии → Ctrl+Alt+V. Набор доходит до Claude Code, ChatGPT, Claude и Telegram.

## План

Порядок предложен 2026-10-19, пользователь может менять.

1. **Проверки на KDE** (дёшево, находки влияют на остальное): режимы «файлы + текст» и склейка в чатах, перетаскивание из ленты, русская раскладка, 50 вставок подряд, разный масштаб мониторов.
2. ✅ **Новые формы меток: стрелка и карандаш** — сделано 2026-10-19, см. [ADR 0006](decisions/0006-arrow-and-freehand-marks.md). Ниже — исходный план (просьба пользователя 2026-10-19; стрелка — EDT-9, карандаша в ТЗ нет). Обе — такие же нумерованные метки с комментарием, как прямоугольник: общая нумерация A1, A2…, строка в тексте сообщения, список комментариев. Пример, как это выглядит у других: стрелка A1, рамка A2, обвод от руки A3.
   - **Модель:** `Mark` получает форму (`Rect`, `Arrow`, `Freehand`) и список точек в физических пикселях исходника; `rect` остаётся охватывающим прямоугольником для поиска и обрезки. Отмена заработает без доработок: она устроена на снимках состояния всего набора (`CaptureSetModel`).
   - **Значок номера:** прямоугольник — левый верхний угол (как сейчас); стрелка — у хвоста (начальной точки); карандаш — у первой точки. Значок всегда внутри снимка (EDT-3).
   - **Рисование:** в общей функции `paintMarks`, чтобы редактор и запекание совпадали. Толщина и наконечник стрелки масштабируются по DPI снимка; та же белая обводка для контраста. Линию карандаша упрощать (Рамер — Дуглас — Пекер) и сглаживать, чтобы не хранить сотни точек.
   - **Редактор:** кнопки «▭ Метка», «➚ Стрелка», «✎ Карандаш» и клавиши R / A / P; комментарий открывается после отпускания мыши, как сейчас. Попадание курсором — по расстоянию до линии, а не по прямоугольнику. Стрелку можно тянуть за концы, рисунок карандашом — только целиком.
   - **Обрезка:** форма целиком вне области — удаляется с подтверждением (как метки сейчас); частично — обрезается при рисовании.
   - **Тесты:** нумерация смешанных форм, запекание стрелки и карандаша, попадание по линии, обрезка.
   - ✅ Цвет, толщина и тип линии для каждой метки — сделано 2026-10-19 по просьбе пользователя, [ADR 0007](decisions/0007-mark-pen.md). Там же: каждый снимок открывается с инструментом «Метка».
3. ✅ **Пакет .rpm, автозапуск, установка .desktop-файла и значка** — сделано 2026-10-19 (docs/build.md, раздел «Пакет .rpm»). Осталось: поставить rpm на чистую систему, собрать .deb на Ubuntu.
4. ✅ **Мастер первого запуска** (APP-4) — сделано 2026-10-19, [ADR 0009](decisions/0009-setup-wizard.md). На живой сессии KDE пройден 2026-10-20; найдено и исправлено: открывался при каждом запуске (docs/problems.md).
5. 🟡 **GNOME 50**: портал Clipboard для режима 1 — реализован 2026-10-19, на KDE проверен 2026-10-20 (`pastetest --portal-clipboard`), осталось GNOME 50; проверка запасных режимов и фокуса оверлея — нужна система с GNOME. **Sway и Hyprland**: `virtual-keyboard-v1` — сделано, самотест во вложенном Sway проходит (ADR 0010).
6. 🟡 **X11** — сделано 2026-10-19 (ADR 0011), проверено на Xvfb. Осталось: настоящая X11-сессия, замер захвата на 4K.
7. **Уведомление KDE «Удалённо управляемый сеанс начат» при каждой вставке** — открыто, решение (держать сессию RemoteDesktop несколько минут) описано в docs/problems.md (2026-10-20), пока не реализуем.
8. **Сборка пакетов в контейнерах** (решение пользователя 2026-10-20: после того, как закончим функции для Linux). Скрипт `tools/package/build-in-container.sh <образ>` → `build-pkg/<система>/`; сначала Fedora 44, Ubuntu 24.04 и Debian 12. Сборка на Ubuntu с Qt 6.4 проверит, что код не использует API новее (ТЗ разд. 7); найденное — исправить. Инструкция — в docs/build.md. Потом — CI на том же скрипте.
