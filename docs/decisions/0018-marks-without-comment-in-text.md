# 0018. Метки без комментария не попадают в текст сообщения

- Статус: принято (2026-10-20, просьба пользователя)
- Требования ТЗ: разд. 3 («Комментарий… может быть пустым — тогда в сообщение уходит только номер»), разд. 10 (шаблон: «пустые комментарии дают строку только с номером, снимки без меток дают только заголовок»), PST-3

## Контекст

Пользователь поставил на единственный снимок стрелку без комментария и получил в чате текст «Снимок A / A1» — он ничего не сообщает, только засоряет сообщение.

## Решение

`buildMessage` (`src/core/MessageBuilder.cpp`):
- метка любой формы без комментария строки не даёт; номера остальных — как на картинке (если у A1 слов нет, а у A2 есть, в тексте «A2 …»);
- единственный снимок без комментариев не даёт ничего, даже «Снимок A»; вводная и заключительная фразы из настроек остаются;
- из нескольких снимков у снимка без комментариев остаётся заголовок: по нему видно, какая картинка какая.

Пустой текст не вставляется вовсе: в режиме 1 — без шага «текст», в режиме «файлы + текст» — без текстовой части, в `message.md` (APP-6) — только картинки.

## Рассмотренные варианты

- Убирать заголовки снимков без комментариев и при нескольких снимках. Пользователь просил только про единственный снимок; заголовки нескольких снимков связывают буквы на картинках с порядком вставки. Можно поменять, если окажется лишним.

## Последствия

- Расходится с ТЗ (разд. 3 и 10) — строка в docs/deviations.md.
- Тесты `MessageBuilder.MarksWithoutCommentAreSkipped`, `MessageBuilder.SingleShotWithoutCommentsGivesNoText`, `MessageBuilder.ShotWithoutCommentsAmongSeveralGivesHeaderOnly`.
